# CONTRIBUTING
To contribute you will need a github account. Main is a protected branch, so all contributions must be reviewed by another person with write access before it can be merged.

## Steps
#### 1. Issue
* Open an issue
* issues titles should be short and descriptive
* issue body should expand on the title and provide reasoning and motivation for the issue

#### 2. Develop
* Checkout a local branch to develop on
* Make modifications
* Push to branch

#### 3. Pull Request
* Open a pull request
* If this pull request is in connection to an issue make sure to reference it
* Be open to feedback
* Wait for review


## Reviewing
* nitpicks that are not critical to the codes success should be marked as so
