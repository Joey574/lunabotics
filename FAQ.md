# FAQ

Q: What software are we using? <br>
A: We will be using a wide set of software, the primary tool we will be using however is ROS2.

Q: What programming language are we using? <br>
A: It is likely we will use languages like C++/Go/Python, most development will be done in C++.

Q: I don't know C++ can I still contribute? <br>
A: Absolutely, there's numerous ways for people to contribute outside of directly programming, 
and C++ is a language like any others and can be learned.

Q: I'm unable to make a certain meeting, is that ok? <br>
A: Of course, while we would always prefer an in-person environment, we understand that is not feesable for everyone. 
Programming is uniquely suited to remote work and nothing we do inherently requires us to be in person.
